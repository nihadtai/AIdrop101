# AI Context: Start Here

Use this tree as the project memory for future implementation agents. Read `architecture/system-map.md` and then only the folder tied to the requested change. Every document names the implementation files, inputs/outputs, dependencies, and risks needed to modify that area without loading unrelated code.

For an unfamiliar task: identify its boundary, read its focused document, inspect the cited code with `rg`, make the smallest compatible change, run the focused checks in `governance/verification.md`, then update the affected context document.
